# Documentation

Welcome to the UniflyIO documentation. These guides are organized so you can go from setup to production operations without reading source code first.

1. [Getting Started](./GETTING_STARTED.md) — get the bot running and deliver the first post.
2. [Configuration](./CONFIGURATION.md) — understand secrets, bindings, and brand constants.
3. [Deployment](./DEPLOYMENT.md) — publish to Cloudflare and connect Telegram webhook.
4. [Bot Usage](./BOT_USAGE.md) — learn the full Telegram user flow.
5. [Operations](./OPERATIONS.md) — monitor, debug, and maintain a running instance.
